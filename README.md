# PlanBee
Grupo 1 - Projeto 23: Evento em Equipe

## Escopo do projeto

Projeto educacional exclusivamente front-end, desenvolvido com HTML, CSS e JavaScript. Sem backend, APIs de autenticação ou integração de pagamentos. Login, cadastro, planos e colaboração serão demonstrações locais, sem senhas reais nem dados sensíveis.

- `index.html`: página pública (Home deslogada).
- `pages/dashboard.html`: Home logada demonstrativa.
- `pages/`: demais páginas internas.
- `css/`: estilos globais, por página, modais e temas.
- `js/`: scripts compartilhados, por página e por funcionalidade.
- `assets/`: imagens, ícones e fontes.

As interfaces ainda estão em desenvolvimento. Abra `index.html` para iniciar a página pública ou `pages/dashboard.html` para desenvolver o painel interno diretamente.
